## Key Decisions Made

1. **Master modules are immutable authority** — never modify the 13 `.ts` files without explicit permission. The 100-record index is reference-grade (~50% confidence) and never overrides master data.

2. **Master modules get full data enrichment; index entries get clean/minimal data.** No hallucinated fields on index entries.

3. **Captain's type overrides:** Copper → CRM, Bauxite/Phosphates/Fluorspar → MIN, Salt → MAR, Gum Arabic → FOR.

4. **Replacement candidates flagged:** Aluminium (rank 17), Aluminium Ingots (rank 73), Steel & Iron Products (rank 55).

5. **Intelligence Briefing format:** Top-10 with Classification/Core Brief/Strategic Impact/Opportunity, persona + location + updated header. Only Crude Oil has a full 10-item briefing authored.
